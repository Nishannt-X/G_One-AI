## Architecture (as built)

Java 21, Spring Boot 3.5.5, three starters only (web, websocket, test); no database, no Redis, no new dependency
([DECISIONS](DECISIONS.md), "trimmed set"). Rooms, clips and agreement state live in **server memory on one instance**
and are lost on restart.

```text
Phone --HTTPS multipart WAV (max 30 s)--> POST /api/rooms/{id}/turns
        Gnani Prisma (REST, speech to text) -> translation (OpenAI-compatible chat call) -> Gnani Timbre (REST, voice)
Both phones <-- WebSocket events (notifications only); the listener alone fetches the translated audio
Async after each turn, never blocking it: caution check (both roles), price offer read (buyer turns), agreement logic
```

- Auth: unguessable room id plus a per-person bearer token; an access code guards room creation.
- Code map: `com.example.g_one` (`room`, `turn`, `speech`, `advisory`, `agreement`, plus the static site in
  `src/main/resources/static`). `com.example.g_one_legacy` (the old Twilio/Deepgram/JPA prototype) is **tracked but excluded
  from compilation**. The tracked `G-One architecture` file and any legacy claims (PSTN, real time, deal locking) are not
  to be reused; the single source for public wording is FARMER-CALL-07.
- Details and run steps: [DEMO.md](DEMO.md#how-it-works). Decisions with reasons: [DECISIONS.md](DECISIONS.md). Terms:
  [GLOSSARY](GLOSSARY.md).

## Decisions that must stay as they are

- **Nonbinding summary, by voice only.** A clear buyer offer opens a draft; the farmer's spoken acceptance triggers a
  read-back to each person in their language; both phones must report playing it to the end; each person then says "Yes,
  I agree". Two plain yes replies produce one summary that says it is nonbinding, not a contract or payment instruction,
  and that identities were not verified. No tap or button confirms anything. Played means "the clip ended on that phone",
  never "the person heard it" ([guarantee](DEMO.md#agreement-by-voice-nonbinding)). The unclear-confirmation retry is a
  spoken one (human's choice, built).
- **Cautions are a courtesy, not a control.** Fixed wording, never echoes what was said, translated speech is delivered
  unchanged, each caution reaches one person only. No claim of blocking, intercepting, shielding or safety.
- **Price wording** is always "AGMARKNET listed ₹X per quintal for <crop, variety, market> on <date>, a dated reference".
  Never "today's price", "modal", "fair" or "live rate".
- **Say / never say** table: [FARMER-CALL-07](FARMER-CALL-07-nov10-architecture-scope.md). Use synthetic names, examples
  and prices in anything public; no real phone numbers or recordings.
- Still open for the human: where WhatsApp numbers come from, and a stale-price fallback ([map fog](FARMER-CALL-WAYFINDER.md)).

## Telephony decision

Browser over mobile data was chosen; this is not PSTN and uses no carrier ([FARMER-CALL-01](FARMER-CALL-01-telephony-gate.md)).
A Twilio **trial account blocks Media Streams (`<Stream>`)**, which a phone-call path needs, so a real call needs a paid
Twilio account the human would arrange and verify ([FARMER-CALL-05](FARMER-CALL-05-account-probe.md), still open and
off the Nov 10 route). Vonage trial and Exotel streaming were ruled out in FARMER-CALL-01. The Twilio WhatsApp Sandbox for
the summary is a separate, unverified account step.

## Runtime state and operating rules

- **No demo processes or tunnel exist now.** On 2026-11-07, read-only checks found nothing listening on ports 8080 or
  18080 and no `java`, `ngrok` or `cloudflared` process. Any earlier room, public URL and in-memory state is gone. Do not
  say a demo link is live.
- To go live, the human must supply secrets through a **fresh secure prompt** (Gnani and translation keys, access
  code). They were never in Git. Do not ask for them in chat and do not read credential or environment files.
  Non-secret variables are listed in [DEMO.md](DEMO.md#run-locally); the six `G_ONE_AGMARKNET_*` ones (all or none) are in
  [DEMO.md](DEMO.md#live-market-price-agmarknet-read-only-no-key). Old `AISETU_*` names still work as fallbacks
  ([renamed configuration](DEMO.md#renamed-configuration)).
- **Stop/start rule (private jar).** `mvn package` can rewrite the jar a running server loaded from, which hangs its
  requests with zero bytes while `/api/config` can still answer. Always run a **private copy** of the jar from a fresh
  temporary directory, and check `/` as well as `/api/config` ([DEMO.md](DEMO.md#run-locally)). Stop the server before
  starting a new one; a restart drops all rooms, so create a fresh room afterwards.
- Longer turns (over 48 KB) rely on macOS `afconvert` for a server-side AAC step: a demo-Mac workaround, not portable.
- Translation model is configuration (`G_ONE_LLM_*`). The 2026-11-06 probe used Groq `qwen/qwen3.8-27b`
  ([old handoff](HANDOFF-2026-11-06.md)); verify the running value rather than trusting any doc, including the research
  file, which names a different model.
- **Live model caveat.** The caution classifier, the price-offer reader and the agreement-reply check are all prompts to
  a live model that no automated test touches. Treat every claim about what they flag, accept or reject as unproven
  until a real-speech run. A spoken secret reaches the model several times (translation, caution check, offer read,
  agreement check); this is documented, not hidden.
- Gnani credit balance is unknown.
